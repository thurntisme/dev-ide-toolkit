# /plan Command

Trigger: `/plan "implement feature..."`

## Usage

```
/plan "implement feature"     # Create plan
/plan "fix bug"              # Create fix plan
```

## Quick Reference

1. Understand requirements from user
2. Analyze codebase
3. Break into tasks
4. Create PLAN.md in `dit-tmp/plans/`
5. Present to user for confirmation
