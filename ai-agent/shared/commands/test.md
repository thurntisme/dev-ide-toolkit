# /test Command

Trigger: `/test` or `/test "module"`

## Usage

```
/test                 # Run all tests
/test "auth module"   # Run specific test
/test --coverage      # Run with coverage
```

## Quick Reference

1. Identify files to test
2. Analyze existing test patterns
3. Generate test file if needed
4. Write test cases
5. Run tests
6. Report coverage
