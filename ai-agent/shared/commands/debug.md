# /debug Command

Trigger: `/debug` or `/debug "fix error..."`

## Usage

```
/debug                    # Debug current error
/debug "fix login error"  # Debug specific issue
```

## Quick Reference

1. Identify error message/behavior
2. Locate relevant files
3. Analyze root cause by language
4. Implement fix
5. Verify fix works
