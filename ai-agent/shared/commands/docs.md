# /docs Command

Trigger: `/docs init` or `/docs update`

## Usage

```
/docs init       # Create docs folder
/docs update     # Update existing docs
```

## Quick Reference

**/docs init:**
1. Check if docs folder exists
2. Ask user for documentation type
3. Create folder structure
4. Generate files

**/docs update:**
1. Verify docs folder exists
2. Compare code changes with docs
3. Update affected docs
4. Update CHANGELOG.md
