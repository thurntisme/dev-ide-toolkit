# Project Management Guide

## When to use
- User asks about project planning
- User asks about task management
- User asks about team coordination
- User asks about project timelines

## Project Lifecycle

1. **Planning** - Define scope, goals, deliverables
2. **Execution** - Build, test, deploy
3. **Monitoring** - Track progress, manage risks
4. **Closure** - Review, document lessons learned

## Agile Workflows

### Sprint Planning
- Define sprint goal
- Estimate story points
- Commit to sprint backlog

### Daily Standup
- What was done yesterday
- What will be done today
- Any blockers

### Sprint Review
- Demo completed work
- Gather feedback
- Update product backlog

### Retrospective
- What went well
- What needs improvement
- Action items for next sprint

## Task Management

| Status | Description |
|--------|-------------|
| Backlog | Prioritized feature list |
| To Do | Ready for development |
| In Progress | Currently being worked on |
| Review | Awaiting code review |
| Done | Completed and deployed |

## Estimation Techniques

- **Story Points** - Relative sizing (1, 2, 3, 5, 8, 13)
- **Planning Poker** - Team consensus
- **T-Shirt Sizes** - S, M, L, XL
- **Velocity** - Average points per sprint

## Risk Management

- Identify potential risks
- Assess impact and probability
- Create mitigation plans
- Monitor and update regularly

## Communication

- Keep stakeholders updated
- Share progress reports
- Conduct regular meetings
- Document decisions

## Tools

- Project tracking: Jira, Trello, Linear
- Documentation: Confluence, Notion
- Communication: Slack, Teams
- Version control: Git
