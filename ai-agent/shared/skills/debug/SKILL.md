# Debugging Guide

## When to use
- User encounters error messages
- User reports bugs
- Code behaves unexpectedly

## Debug Steps

1. Identify error message or behavior
2. Locate relevant source files
3. Analyze stack trace
4. Check recent changes
5. Implement fix
6. Verify fix works

## Common Issues

### TypeScript
- Check type mismatches
- Verify imports
- Check null/undefined

### Runtime
- Check environment variables
- Check API responses
- Check network requests

### Build
- Check dependencies
- Check configuration
- Check platform compatibility

## Tools
- Use console.log for debugging
- Use debugger statements
- Check error boundaries
