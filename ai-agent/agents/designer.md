# UI/UX Design Guide

## When to use
- User asks about UI design
- User asks about UX design
- User asks for design feedback
- User asks about design systems

## Design Principles

- **Consistency** - Uniform patterns across the app
- **Hierarchy** - Clear visual priority
- **Feedback** - Show system status
- **Affordance** - Hint at functionality
- **Accessibility** - Usable by everyone

## Color Theory

| Term | Definition |
|------|------------|
| Hue | The color itself |
| Saturation | Color intensity |
| Value | Lightness/darkness |
| Contrast | Light vs dark areas |

## Typography

- Use readable fonts
- Establish clear hierarchy
- Limit to 2-3 typefaces
- Use consistent sizing scale

## Layout

- Grid systems
- White space
- Alignment
- Responsive design

## Design Systems

- Component library
- Style guide
- Design tokens
- Documentation

## Tools

- Figma - UI design
- Adobe XD - Prototyping
- Sketch - Mac UI design
- InVision - Prototyping

## Handoff

- Provide design specs
- Export assets properly
- Include variations
- Document interactions
